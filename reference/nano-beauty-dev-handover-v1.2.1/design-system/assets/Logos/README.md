# Logos

The logo is only ever the full "nano BEAUTY" lockup from the master artwork.

- `nano-beauty-logo-master.svg` — the master exactly as supplied: square logo-plum (#463E55) ground with the white lockup. App icon (supply at 1024×1024, the OS masks the corners), splash, store listing, social avatar.
- `NBS-White-Logo-master.pdf` — the original vector file from the client (Adobe Illustrator PDF). The source of truth.
- `nano-beauty-lockup-plum.svg` — the same lockup without the square, in logo plum #463E55, for light grounds. In code use the `Logo` component, which takes its ink from CSS `color` (`ink-display` on light grounds, `on-brand` on `surface-brand`).

Never separate "nano" from "BEAUTY", recolour the master, or redraw any letter.
