# AreaPicker

Chooses several areas for per-area treatments such as laser, with a running total (DISC 07, G27).

**Props:** `areas` (`{name, price, selected}`), `set` (`women`, `men`), `max`, `total`, `note`.

**States:** none picked, some, maximum reached (other areas disabled), women's or men's area set. The total comes from the catalogue; bundle prices are shown, not calculated in the app.
