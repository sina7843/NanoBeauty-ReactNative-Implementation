# Badge

A short status label: one or two words with an icon, never colour alone.

**Props:** `tone` (`neutral`, `primary`, `success`, `warning`, `danger`, `info`, `sample`), `icon` (defaults per tone; pass `null` to hide), `children`.

`sample` (dashed outline) marks **simulated data** in designs and demo builds. Every authenticated balance, appointment or staff record shown before real data is connected must carry it.
