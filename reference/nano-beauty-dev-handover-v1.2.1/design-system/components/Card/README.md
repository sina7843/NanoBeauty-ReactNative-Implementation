# Card

The basic rounded container: opaque, `radius-lg`, hairline border, no heavy shadow.

**Props:** `tone` (`surface`, `tint`, `brand`), `padded`, `onPress` (makes the whole card one button with a pressed state), `children`.

`surface` holds anything the customer must be able to trust and read: price, booking, wallet, consent, aftercare. `tint` is for clinic value and offers. `brand` is for a guest hero or splash, one per screen. No translucent or blurred cards.
