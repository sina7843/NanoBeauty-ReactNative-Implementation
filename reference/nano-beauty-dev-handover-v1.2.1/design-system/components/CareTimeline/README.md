# CareTimeline

Preparation and aftercare tied to a real appointment (NOTIF 03, DISC 06).

**Props:** `steps` (`{when, title, text, state}` where state is `done`, `now` or `upcoming`).

Text comes only from clinic-approved content for that service. No progress percentages, no photos, no predicted results, no symptom checking. Escalation copy points to the clinic or emergency services. Static by default; no animated progress.
