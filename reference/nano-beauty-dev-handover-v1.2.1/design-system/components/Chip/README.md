# Chip

Toggleable filter and concern chips (DISC 04–05).

**Props:** `selected`, `count`, `icon`, `disabled`, `children`.

**Selected** = `surface-tint` fill, `primary` border, `on-tint` label and a check mark, so selection never relies on colour alone.

**Use** for concern-led browsing and filters (category, concern, price type, duration, professional). Chips scroll horizontally in one row; a "Filters" chip opens a sheet with the full set. Concern labels need clinical review before release.
