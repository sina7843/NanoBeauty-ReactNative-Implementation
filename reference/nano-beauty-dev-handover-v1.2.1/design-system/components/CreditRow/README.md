# CreditRow

Clinic credit shown as clinic value, not a bank card: available, pending, source, restrictions and expiry (WALT 10–11).

**Props:** `available`, `pending`, `source`, `expires`, `reconciling`, `sample`.

Always says "non-cash" and where it can be used. While the ledger is reconciling, show a dash and "Checking your balance", never a guessed or old number presented as current. No count-up animation.
