# GiftCard

A gift card as the customer holds or sends it: brand face, masked code, balance and delivery status (WALT 01–04).

**Props:** `amount`, `balance`, `recipient`, `status` (`payment`, `scheduled`, `sent`, `claimed`, `refunded`), `code` (masked), `sample`.

The face is plum with the full "nano BEAUTY" lockup; the balance is the only large figure. Codes are masked until the owner reveals them. Terms, expiry (where legal) and redemption scope link below the card. Gift designs from the old app are not carried over.
