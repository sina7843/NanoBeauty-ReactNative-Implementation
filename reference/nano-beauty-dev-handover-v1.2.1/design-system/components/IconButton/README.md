# IconButton

A 48×48 icon-only control for close, filter, edit and notifications.

**Props:** `icon`, `label` (required: the accessible name and tooltip), `variant` (`plain`, `tonal`, `outline`), `badge` (a violet dot meaning "new"; never a count of unread marketing), `disabled`.

**Use** only where the icon is universally understood; otherwise use a `Button` with a label. Never put the only way to reach a key task behind an icon button.
