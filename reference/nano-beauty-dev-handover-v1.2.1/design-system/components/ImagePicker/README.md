# ImagePicker

Adds or replaces a photo on a service, campaign, package or professional, and shows it in the media library (ADMIN 02, G17). `MediaTile` is the library grid item.

**Props (ImagePicker):** `src`, `state` (`empty`, `uploading`, `uploaded`, `small`, `rights`, `alt`), `label`, `alt`, `ratio`, `progress`.
**Props (MediaTile):** `src`, `name`, `rights`, `alt`, `selected`.

A photo can't be published until its rights are confirmed and it has alt text. Minimum width is 1,050 px (3× a 350 pt slot).
