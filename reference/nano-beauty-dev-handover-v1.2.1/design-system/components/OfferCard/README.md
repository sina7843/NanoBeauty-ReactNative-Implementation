# OfferCard

A remotely published campaign with terms and an exact destination (PROMO 01–05, PROMO 09).

**Props:** `eyebrow`, `title` (serif, short), `summary`, `endsAt` (absolute time and timezone from the server), `state` (`live`, `upcoming`, `expired`, `paused`), `photo`, `cta`.

**Rules**
- Show two campaigns at most on Home (DISC 11). No auto-advancing carousels.
- The CTA opens the exact eligible service, package or booking path. Expired and paused offers go to a safe destination with an explanation.
- Material terms are one tap away, before booking or purchase.
- Countdowns are plain text updated from server time; no flashing timers.
