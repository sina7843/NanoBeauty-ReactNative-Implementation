# PackageBalance

A multi-session package: sessions used, booked and left, expiry and the next booking action (WALT 05–07, BOOK 14).

**Props:** `name`, `total`, `used`, `pending` (sessions booked but not yet done), `expires`, `status` (`active`, `expiring`, `expired`), `sample`.

Dots show used (hollow), booked (dashed) and left (violet), and the sentence repeats it in words. Balances come from the ledger (WALT 11); discrepancies link to support. Never animate a balance change.
