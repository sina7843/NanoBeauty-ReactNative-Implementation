# PhotoFrame

A fixed-ratio image frame that crops photography consistently and shows a labelled placeholder until licensed images arrive.

**Props:** `src`, `alt` (required with a real photo: describe the treatment context, not the person's looks), `ratio` (`4 / 3`, `16 / 10`, `16 / 9`, `1 / 1`), `label` (placeholder text).

**Imagery rules:** real clinic photography with natural light and real skin texture; the face or treatment area sits in the upper-centre third so crops at every ratio keep it. No before/after images in cards or campaigns; those need clinical approval and a dedicated, consented context. No stock-spa clichés (stones, orchids, towels). Placeholders stay visibly placeholders in every handoff.
