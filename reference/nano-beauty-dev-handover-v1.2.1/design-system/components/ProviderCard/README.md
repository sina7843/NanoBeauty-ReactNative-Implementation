# ProviderCard

A selectable professional in booking (BOOK 02), with the team photo from the website or initials when there is none.

**Props:** `name`, `role` (approved title only; no unverified credentials), `note`, `selected`, `anyone` (the "Any professional" option, listed first when supported), `disabled`.

Selection = 2px `primary` border, `surface-tint` fill and a filled radio. Ineligible professionals are either hidden or disabled with a reason, per clinic rules. Staff names shown in previews are sample content.
