# StaffBar

The header of every staff screen: a deep plum band that makes the staff workspace unmistakable, with role and environment (ADMIN 01, ADMIN 07).

**Props:** `title`, `role` (Owner, Editor, Front desk; D34), `env` (`Production`, `Staging`, `Development`; non-production shows an amber tag), `layout` (`phone`, `tablet`: wider padding, role on the right; D39).

Staff enter the workspace from Account, only after the server confirms a staff role. It is never a customer tab. Every staff screen uses this band; customer screens never do.
