# StatTile

One number on staff home and reports, with change against the last period and a small bar history (PROMO 08, G19).

**Props:** `label`, `value`, `change`, `trend` (`up`, `down`), `bars` (numbers; the last is highlighted), `state` (`ready`, `empty`, `loading`), `period`.

The change is always written as text with an arrow, never colour alone.
